# 🥘 Zomato Data Analysis Project
## 📖 Project Overview

The Zomato Data Analysis Project aims to explore and analyze restaurant data from Zomato to uncover useful business insights.
This project focuses on understanding restaurant trends, online ordering behavior, ratings distribution, cost patterns, and location-based performance.

## 🎯 Objectives

Analyze customer preferences and restaurant types.

Study how online ordering impacts restaurant ratings.

Visualize the distribution of approximate costs for two people.

Identify the most popular restaurant types and cuisines.

Generate insights for restaurant business improvement and decision-making.

## 📊 Dataset Information

The dataset contains details about restaurants listed on Zomato.
Some important columns include:

name – Name of the restaurant

online_order – Whether online ordering is available

book_table – Availability of table booking

rate – Customer ratings

approx_cost(for two people) – Average cost for two

listed_in(type) – Type of restaurant (Buffet, Café, Delivery, etc.)

cuisines – Type of cuisine offered

location – Restaurant location

## 🧠 Key Analysis Performed

Count of restaurants by type using Seaborn countplot

Relationship between online order availability and rating using boxplots

Most popular cuisines and restaurant types

Distribution of restaurant costs for two people

City/location-based restaurant analysis

Comparison of restaurants offering table booking vs. not

## 🧰 Tools & Libraries Used

Python

Pandas – for data cleaning and analysis

NumPy – for numerical operations

Matplotlib & Seaborn – for visualization

Jupyter Notebook / VS Code – for coding environment

## 📈 Visualizations

Some of the key visualizations include:

Count plots for categorical features (online_order, listed_in(type))

Box plots to compare rate with online_order and book_table

Bar charts for top cuisines and cost distribution

Heatmap showing correlations among numerical variables

## 💡 Insights

Restaurants with online ordering tend to receive slightly higher ratings.

Cafés and Quick Bites are the most common restaurant types.

The average cost for two people mostly lies between ₹300–₹800.

Certain locations have a higher concentration of high-rated restaurants.

Availability of table booking positively influences customer ratings.

## 🧾 Conclusion

The Zomato dataset reveals strong relationships between customer satisfaction, pricing, and restaurant facilities like online ordering and table booking.
These insights can help restaurant owners make better business decisions, optimize pricing, and improve service features.
